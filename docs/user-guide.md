# User Guide

## Start

Open `http://localhost:8080`, select **Register**, and create an account with an email and a password of at least eight characters. The account receives the `User` role automatically.

## Create and manage quests

Open **Quests**. Enter a title, choose a skill and difficulty, optionally add a description, then select **Add to quest log**. Search and filter the archive by status or difficulty. Use **Edit** to change an active quest. **Delete** opens a confirmation panel before removal.

## Complete a quest

Select **Complete** on an active quest. QuestForge awards XP according to difficulty: Easy 10, Medium 25, Hard 50, Epic 100. The Dashboard updates total XP, level, skill XP, history, and newly unlocked achievements. A completed quest cannot award XP again.

## Dashboard

The Dashboard displays current level, progress to the next level, completed quests, achievements, skill progress, and recent activity. Each account sees only its own data.
